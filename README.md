# LapAgent

桌面 AI Agent 助手 - 综合型智能助手，支持系统控制、多模态交互和智能对话。

## 项目愿景

LapAgent 是一个强大的桌面 AI 助手，能够：
- 🤖 智能对话与问答
- 🖥️ 控制系统应用（浏览器、文件管理器、终端等）
- 👁️ 多模态交互（屏幕理解、语音交互）
- 🔧 自动化任务执行

## 技术栈

- **后端**: Python 3.10+ (FastAPI)
- **前端**: Tauri (Rust) + React + TypeScript
- **AI**: OpenAI API (GPT-4/4o)
- **工具系统**: Function Calling 框架

## 项目结构

```
LapAgent/
├── backend/          # Python 后端服务
├── frontend/         # Tauri + React 前端
├── shared/           # 共享配置和类型定义
├── docs/             # 文档
└── scripts/          # 构建和部署脚本
```
